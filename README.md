A single 1024×1024 image summing up Tuesday 24 November 2026: a chronological
timeline of twelve world stories, led by the Strait of Hormuz tanker attacks.
Every story carries a headline, one line of fact, and a region tag — the image
reads alone, with no outside context needed. All events are dated
24 November 2026 in their origin timezone.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (and `/output/entry.png`). Pure Pillow, no network access,
deterministic — two runs produce byte-identical files.
